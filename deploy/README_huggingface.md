# ResumeX

Explainable AI resume screening. Create a job, upload resumes, get a ranked
shortlist where every rank is backed by the lines from the candidate's own resume.

Built with FastAPI, Sentence-BERT (all-MiniLM-L6-v2) and scikit-learn.

**Note for visitors:** this Space stores data in temporary storage, so jobs and
uploaded resumes are cleared when the Space restarts.
